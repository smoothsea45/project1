# 의약품 제조원가율 시뮬레이터

**설치 없이 브라우저에서 사용하는 웹 버전**입니다. 제품의 처방, 원료 구매단가, 배치사이즈, 수율과 고정 비용을 입력하면 제조원가율이 즉시 계산됩니다. **입력 / 결과 / 시나리오 비교**를 세 개의 버튼형 탭으로 나누었으며 한국어로 사용할 수 있습니다.

## 바로 사용하기

1. GitHub의 **Code → Download ZIP**을 누릅니다.
2. ZIP을 폴더에 모두 풉니다.
3. **web/index.html**을 더블클릭해 Edge·Chrome 등 최신 브라우저에서 엽니다. 루트의 `index.html`을 열어도 같은 프로그램으로 이동합니다.

Python·npm·서버 설치가 필요하지 않습니다. 전체 폴더를 회사 PC에 복사하면 인터넷 없이 실행합니다. HTML 파일만 복사하지 말고 `web` 폴더의 JavaScript·CSS·`vendor` 파일을 함께 유지하세요. 입력값은 외부 API·서버로 전송하지 않고 브라우저에서 계산합니다.

화면 사용법과 파일 저장 안내는 [웹 버전 사용 안내](docs/web-usage.md)에 있습니다.

## 웹 버전의 계산과 저장

- 제품명·비고를 입력하고 API·부형제를 여러 행으로 추가합니다. 원료 단가 단위는 **원/g, 원/kg, 달러/g, 달러/kg**이며 달러 단가는 시나리오의 공통 USD 환율을 적용합니다.
- **배치사이즈는 손실 발생 전 기준 수량**입니다. 수율 기본값은 100%이며 원료·포자재·공수의 모든 1T당 비용을 `배치 비용 ÷ (배치사이즈 × 수율)`로 계산합니다. 수율 80%는 0.8로 적용합니다. `T`는 계산하는 한 단위제형을 뜻합니다.
- 포자재비·공수비는 배치 전체 금액을 입력합니다. 제조원가는 API·부형제·포자재비·공수비의 1T당 비용 합계이고, 원가율은 이 금액을 우리 제품 예상 보험약가로 나눈 값입니다.
- **현재 입력 복제**로 독립적인 시나리오를 만들고 공급처·단가·환율·수율·약가 등을 바꿔 비교합니다.
- **프로젝트 저장**으로 JSON 파일을 다운로드하고 **파일 열기**로 다시 불러옵니다. 브라우저가 허용하면 입력 중 초안도 해당 브라우저에 자동 보관·복원합니다. 영구 보관과 다른 PC 이동에는 JSON 파일을 사용하세요.

**약가 조건** 제목 옆에서 **직접 입력 / 예상 약가 계산**을 선택합니다. 직접 입력에서는 우리 제품 약가만 약가 계산에 사용하고, 회사·품목·시장 조건은 실제로 비활성화합니다. 원료·배치·고정비용 입력은 계속 사용할 수 있습니다. 수동 약가 원본은 자동 결과와 분리해 보관하므로 모드를 되돌리면 복원됩니다.

예상 계산에서는 조건에 따라 등재일부터 **10년간의 연차별 예상 약가**를 세로 막대로 표시합니다. 처음에는 1년차를 사용하며, 막대를 선택하면 해당 연차의 약가가 결과·원가율·시나리오 비교에 즉시 반영됩니다. 일반 제네릭의 기준요건별 45/36/29%, 기업가산·수급안정 가산·14개 이상 감액과 단계별 원 단위 반올림을 계산합니다. 비생물 자료제출의약품·개량신약 단일제는 별첨1의 확인된 세부 경로를 별도 기준금액으로 계산합니다. 복합제·생물의약품 및 확인되지 않은 가산 조합·기산일 경로에는 **추가 산정조건 필요**를 표시하고 임의 약가를 만들지 않습니다.

규정은 사용자가 지정한 **2026-08-01 기준**으로 고정합니다. 지정된 공식 별표 PDF에서 산식을 확인했으며, 본문·부칙의 시행일은 네트워크 접근 제한으로 독립 확인하지 못했습니다. 적용 범위·원문 인용·가정은 [약가 규정 참고 기록](docs/pricing-reference.md)에 있습니다. 예상치는 선택 조건과 제도 유지 가정에 따르며, 실거래가·사용량 연동 등 사후 조정은 포함하지 않습니다.

웹 JSON은 `pharma-cost-web-project` 형식·**버전 2**입니다. 버전 1 파일·초안은 값을 보존해 이관하되, 예전의 여러 가산 체크나 합쳐진 기업 자격처럼 해석이 모호한 선택은 재확인을 요청합니다. 모드·수동 약가·조건·선택 연차도 저장됩니다. 계산 모델이 다른 기존 데스크톱 JSON은 자동 변환하지 않으므로 원본을 보관하고 기존 프로그램에서 여세요.

## 웹 개발과 검증

정적 HTML·CSS·JavaScript와 저장소에 포함된 Decimal 라이브러리만 사용합니다. `web/engine.js`가 배치 원가 계산·파일 형식, `web/pricing.js`가 약가 규칙·연차별 산정, `web/app.js`가 화면을 담당합니다. 약가의 법정 반올림과 제조원가의 내부 정밀도는 분리합니다. npm 설치나 백엔드는 없습니다. 개발 테스트에는 Node.js가 필요합니다.

```bash
node --test web/tests/*.cjs
```

실제 브라우저 검증 명령과 개발용 의존성은 [웹 버전 사용 안내](docs/web-usage.md#개발-검증)에 있습니다. 테스트 실행 결과는 완료 보고나 실제 명령 출력에서 확인하세요. 향후 Windows 실행파일도 이 웹 계산 엔진을 감싸서 같은 계산을 사용할 수 있도록 설계했습니다. **웹 버전을 감싼 Windows 실행파일은 아직 제공하지 않습니다.**

## 기존 Python 데스크톱 버전

기존 PySide6 프로그램은 이전 계산 모델 그대로 유지합니다. 아래의 개발·Windows 배포 절차는 이 기존 프로그램에 대한 안내입니다.

<details>
<summary>기존 데스크톱 실행·계산·Windows 배포 안내 펼치기</summary>

정제·캡슐의 실제 원료 투입량과 구매단가, 수율, 포장재비, 공수비를 입력해 단위제형당 제조원가와 보험약가 대비 원가율을 계산하는 Python + PySide6 데스크톱 프로그램입니다. 화면과 안내는 한국어이며, 실행 중 서버·로그인·인터넷 연결을 사용하지 않습니다.

기존 데스크톱 버전은 예상 보험약가를 **사용자가 직접 입력**합니다. 검증되지 않은 제네릭·개량신약 약가 산정률을 자동 적용하지 않습니다. 회사 PC에서는 Windows에서 빌드한 배포 폴더 전체를 복사해 Python 설치 없이 실행할 수 있습니다.

### 실행 환경과 개발 실행

Python 3.10 이상이 필요합니다. Windows 배포는 64비트 Python 3.12 사용을 권장합니다. 실행 의존성은 `PySide6==6.8.3`이며 개발·테스트·배포 의존성은 `pytest==8.3.5`, `PyInstaller==6.12.0`입니다. 의존성 최초 다운로드에는 인터넷이 필요하지만 설치 후 앱 사용에는 필요하지 않습니다.

Windows PowerShell에서 저장소 루트 기준으로 실행합니다.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pip install --editable .
.\.venv\Scripts\python.exe -m pharma_cost
```

Linux/macOS 개발 환경에서는 다음 명령을 사용합니다. 실제 화면 실행에는 데스크톱 환경과 운영체제의 Qt 관련 라이브러리가 필요합니다.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pip install --editable .
.venv/bin/python -m pharma_cost
```

같은 앱을 `python run_app.py` 또는 설치된 `pharma-cost` 명령으로도 실행할 수 있습니다.

### 사용 순서

1. 앱을 시작하면 **가상 예제**가 열립니다. 예제 수치는 실제 제품·견적·보험약가 자료가 아닙니다. 저장한 프로젝트는 파일 메뉴의 열기로 불러오고, 실제 제품을 입력하려면 새 프로젝트를 만듭니다. 예제를 수정·저장해도 예제 표시가 유지되며 새 프로젝트에서는 해제됩니다.
2. **제품·약가** 탭에 프로젝트명, 제품명, 제형, 표시 함량과 메모를 입력합니다. 표시 함량은 정보 기록용이고 원료 투입량 계산에 자동 적용되지 않습니다.
3. 같은 탭에 예상 보험약가와 목표 제조원가율을 입력합니다. 필요하면 가산 종료 후 예상 약가도 입력합니다. 제품 유형, 개발 방식, 1+3 참여 형태, 기준 제품·금액 및 약가 관련 조건은 기록용입니다.
4. **원료 입력** 탭에서 API와 부형제를 추가합니다. 각 원료의 실제 투입량과 단가를 입력합니다. 복합제 API는 각각 별도 행으로 입력합니다. 개당 구매하는 캡슐 기제 등은 구매 기준을 개수로 바꿉니다. 표 셀 편집은 Enter·Tab 또는 다른 셀로 이동하면 반영됩니다.
5. 구매단가의 원화 직접 입력 또는 외화 환산 방식을 선택합니다. 외화 환산 행은 외화단가와 환율로 계산하며, 견적일·공급처·규격·메모도 기록할 수 있습니다.
6. **수율·고정 비용** 탭에서 원재료비 수율 보정을 선택하고 수율을 입력합니다. 포장재비·공수비는 단위제형, 포장, 배치 중 받은 자료의 기준을 선택한 뒤 금액과 환산 수량을 입력합니다.
7. 입력이 반영되면 **계산 결과** 탭의 원가·원가율·목표 차이·필요 절감액과 비용 구성표 및 차트가 즉시 갱신됩니다. 별도 계산 버튼은 없습니다. 시나리오를 복제하고 이름을 정해 수정하면 원본을 유지한 채 **시나리오 비교** 탭에서 나란히 비교할 수 있습니다.
8. 파일 메뉴에서 JSON 프로젝트를 저장합니다. 프로젝트 하나에 제품정보, 모든 원료·비용·약가 정보와 시나리오가 들어갑니다. 저장하지 않은 수정이 있으면 닫기·새 프로젝트·열기 전에 저장 여부를 확인합니다.

원료표는 Ctrl+C/Ctrl+V로 여러 셀을 복사·붙여넣을 수 있습니다. 엑셀에서 **머리글을 제외한** 탭 구분 셀 범위를 복사하고 원료표의 시작 셀을 선택해 붙여넣으면, 현재 셀부터 값이 들어가며 필요한 행을 추가합니다. 원료표 열 순서를 맞춰 붙여넣으세요. 이 기능은 클립보드 표 입력이며 `.xlsx` 파일 직접 가져오기·내보내기는 이후 버전에서 추가합니다.

### 계산 기준과 가정

계산 단위는 정제의 `원/정`, 캡슐의 `원/캡슐`입니다. 사용자가 입력한 실제 투입량을 계산에 쓰며, 표시 함량에서 염·수화물 환산이나 함량·역가 보정을 추정하지 않습니다.

| 항목 | 계산식 |
| --- | --- |
| 질량 기준 원료 | 실제 투입량(mg/단위제형) × 구매단가(원/kg) ÷ 1,000,000 |
| 개수 기준 원료 | 사용 개수/단위제형 × 구매단가(원/개) |
| 외화 구매단가 | 외화단가 × 환율(원/외화 1단위) |
| 이론 원재료비 | API 비용 합계 + 부형제 비용 합계 |
| 수율 보정 후 원재료비 | 이론 원재료비 ÷ (수율% ÷ 100) |
| 포장 기준 비용 | 원/포장 금액 ÷ 포장당 수량 |
| 배치 기준 비용 | 원/배치 금액 ÷ 배치당 양품 수량 |
| 제조원가 | 수율 보정 후 원재료비 + 포장재비 + 공수비 |
| 보험약가 대비 제조원가율 | 제조원가 ÷ 예상 보험약가 × 100 |
| 허용 제조원가 | 예상 보험약가 × 목표 제조원가율 ÷ 100 |
| 필요 절감액 | max(0, 제조원가 − 허용 제조원가) |
| 목표 원가율과의 차이 | 제조원가율 − 목표 제조원가율 (%p) |

- 수율 기본값은 100%입니다. 모든 원료에 동일한 수율을 적용하는 단순 모델이며, 보정을 끄면 이론 원재료비를 그대로 사용합니다. 포장재비와 공수비에는 이 보정이 적용되지 않습니다.
- API·부형제 합계는 **수율 보정 전** 원료비입니다. 비용 구성은 제조원가와 비교할 수 있도록 수율 적용 여부를 표시합니다.
- 외화단가는 해당 행의 구매 단위 기준입니다. 질량 기준은 외화/kg, 개수 기준은 외화/개이고, 환율은 `원/외화 1단위`입니다.
- 원가율의 분모는 보험약가입니다. 실제 납품가, 부가세, 매출 할인, 판매관리비, 이익률, QC·간접비 별도 산출은 포함하지 않습니다. QC·간접비 등이 받은 고정 비용에 포함되어 있으면 비용 메모에 기록합니다.
- 0원은 무상 원료·비용으로 입력할 수 있지만 환율과 환산 수량은 양수여야 합니다. 수율은 0% 초과, 100% 이하입니다. 필수 비용 값이 비어 있거나 잘못되면 관련 항목을 표시하고 미완성 결과로 안내합니다.
- 약가가 없거나 0이면 제조원가는 계산하고 원가율은 `계산 불가`로 표시합니다. 원가율 100% 초과도 제한하지 않습니다.
- 숫자는 `Decimal`로 계산하고 표시할 때만 반올림합니다. 나눗셈은 유한한 Decimal 정밀도 안에서 계산되며 중간 단계에서 금액을 원 단위로 반올림하지 않습니다.
- 날짜는 자유롭게 기록하는 자료용 정보이며, 외부 약가 규정이나 환율을 자동 조회하지 않습니다.

약가 모듈에는 사용자 입력값의 출처를 구분하고 향후 적용 규정·기준일·산정 과정을 담을 수 있는 구조를 둡니다. 제품 유형과 1+3 참여 형태, 오리지널 현재 약가와 산정 기준금액은 각각 별도로 저장합니다.

### 파일과 확장 구조

화면 코드는 `pharma_cost/ui/`, 제품·시나리오 모델은 `models.py`, 계산은 `calculation.py`, 약가는 `pricing.py`, JSON 저장은 `storage.py`로 분리합니다. 계산 함수는 Qt에 의존하지 않으므로 향후 엑셀 입출력도 동일한 모델과 계산을 사용할 수 있습니다. JSON에는 파일 형식 버전이 있으며 지원하지 않는 버전·잘못된 데이터는 한국어 오류로 안내합니다.

프로젝트 JSON은 사용자가 선택한 경로에 저장됩니다. 실행파일·프로그램 설치 폴더 안보다 문서 폴더 같은 쓰기 가능한 위치에 보관하는 것을 권장합니다. 회사 자료는 일반 텍스트 JSON으로 저장되므로 회사의 파일 접근·백업 정책에 맞춰 관리하세요.

### Windows 실행파일 배포

**Windows 실행파일은 Windows에서 빌드해야 합니다.** Linux나 macOS에서 PyInstaller를 실행해 Windows exe를 만들 수 없습니다.

Windows 10/11 64비트, 64비트 Python 3.12가 설치된 빌드 PC의 PowerShell에서 다음을 실행합니다.

```powershell
.\scripts\build_windows.ps1
```

Python 런처 `py`가 없는 경우 Python 실행파일을 지정합니다.

```powershell
.\scripts\build_windows.ps1 -PythonCommand "C:\Python312\python.exe"
```

빌드 스크립트는 별도 `.venv-build`를 만들거나 기존의 유효한 가상환경을 재사용하고 의존성 설치, 테스트, PyInstaller 빌드를 수행합니다. `pharma_cost.spec`는 `console=False`인 한 폴더 배포를 구성하며 Qt 의존성·플러그인은 PyInstaller의 공식 PySide6 훅으로 수집합니다.

결과물은 다음과 같습니다.

```text
dist/
└── PharmaCostSimulator/
    ├── PharmaCostSimulator.exe
    └── _internal/           # Python 런타임, Qt 및 의존 파일
```

`PharmaCostSimulator` 폴더 **전체**를 ZIP으로 전달하고, 사용자는 압축을 풀어 `PharmaCostSimulator.exe`를 실행합니다. exe 파일만 복사하면 실행되지 않습니다. 사용 PC에는 Python·pip·인터넷 연결이 필요하지 않습니다. 상세 빌드·오프라인 배포·출시 전 확인 절차는 [Windows 배포 안내](docs/windows-distribution.md)를 참조하세요.
