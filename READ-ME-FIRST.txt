의약품 제조원가율 시뮬레이터 — Windows에서 실행해보기

이 ZIP은 프로그램 소스와 실행 도구입니다. Python이 필요 없는 완성 EXE는 아직 아닙니다.

1. ZIP 파일을 내려받고 마우스 오른쪽 버튼 → '압축 풀기'를 선택하세요.
   ZIP 안에서 바로 실행하지 말고, 먼저 전체 파일을 압축 해제하세요.

2. Python이 없다면 Python 3.12 Windows installer (64-bit)를 설치하세요.
   공식 다운로드: https://www.python.org/downloads/release/python-31210/
   페이지 아래 Files에서 Windows installer (64-bit)를 선택하세요.
   설치 화면의 'Add python.exe to PATH'에 체크한 뒤 Install Now를 누르세요.
   이 버전은 간단히 시험 실행하기 위한 Windows 설치 프로그램이 제공되는 버전입니다.

3. 압축을 푼 폴더에서 Start-Windows.bat를 더블클릭하세요.
   처음 실행할 때 필요한 구성요소를 설치하므로 인터넷 연결이 필요합니다.
   잠시 기다리면 한국어 프로그램 창이 열립니다. PowerShell 명령을 입력할 필요는 없습니다.

4. 노란색 '가상 예제' 표시가 있는 화면에서 시작합니다.
   '원료 입력'에서 투입량과 단가를 바꾸고 Enter를 눌러보세요.
   '계산 결과'와 '시나리오 비교'에서 결과를 확인할 수 있습니다.
   실제 자료를 입력하려면 파일 메뉴 → 새 프로젝트를 선택하세요.

5. 이후에도 같은 Start-Windows.bat를 더블클릭하면 실행됩니다.
   처음 설치를 마친 뒤에는 앱 사용에 인터넷이 필요하지 않습니다.
   파일 → 저장으로 JSON 프로젝트 파일을 보관하세요.

실행이 안 되는 경우:
- 검은 창의 오류 메시지를 확인하세요. 오류가 나면 창이 바로 닫히지 않도록 되어 있습니다.
- 회사 PC에서 프로그램 설치 또는 BAT 실행을 제한하면 설치 가능한 다른 Windows PC에서 시험하세요.
- 이 패키지는 Linux에서 계산 및 Qt 화면 테스트를 마쳤지만, Windows 실행 도구는 아직 실제 Windows에서 검증하지 않았습니다.

Python 없이 사용하는 회사 배포본 만들기:
- Windows 빌드 PC에서 scripts/build_windows.ps1을 실행해 EXE를 만들 수 있습니다.
- dist/PharmaCostSimulator 폴더 전체를 회사 PC로 옮겨 실행합니다.
- 자세한 절차는 docs/windows-distribution.md에 있습니다.
