# 간소화 개편 계획 — 검토용

사용자와 확정한 개편 계획이다. 이후 요청에 따라 배치 계산과 두 페이지 화면을 웹 버전으로 구현했다. 약가 자동 산정은 공식 원문 접근이 차단되어 미확인 상태로 남아 있다.

## 확정한 기준

- 제품정보는 **제품명 / 비고** 두 칸만 표시한다.
- 화면은 **입력**과 **결과·시나리오 비교** 두 페이지로 구성한다.
- 단위는 **T(1정 또는 1단위제형)**로 통일하고 원료 투입량은 **mg/T**로 고정한다.
- 배치사이즈는 손실 발생 전 이론 생산 정수이다.
- 수율 기본값은 **100%**이다. 원료와 고정비가 같은 배치사이즈·수율을 사용한다.
- 수율을 반영한 별도 수량은 화면에 표시하지 않는다. 계산 분모에서만 `배치사이즈 × (수율% ÷ 100)`을 사용한다.
- 배치사이즈·수율·환율은 시나리오 안에서 공통으로 사용한다. 서로 다른 시나리오에서는 독립적으로 바꿀 수 있다.

## 입력 페이지

위에서 아래로 제품정보 → 공통 계산 조건 → 약가 조건 → 원료표와 합계 → 고정비 순서로 배치한다. 원료 행이 많으면 표 안에서 스크롤한다. 작은 창에서 필요한 경우 전체 페이지에도 스크롤을 제공한다.

### 제품정보와 공통 조건

| 위치 | 입력 |
| --- | --- |
| 제품정보 한 줄 | 제품명, 비고 |
| 공통 조건 한 줄 | 배치사이즈(T/배치), 수율(%), 환율(원/USD) |

프로젝트명·제형·표시 함량·별도 제품 메모 칸은 제거한다. 저장 파일 이름은 저장할 때 정한다. 환율은 달러 단가를 사용하는 경우에만 계산 필수값으로 검사한다.

### 약가 조건

| 항목 | 선택값 | 예정 방식 |
| --- | --- | --- |
| 오리지널 약가 | 원/T 숫자 입력 | 한 칸 |
| 기업별 가산 | 혁신형 제약기업 / 준혁신형·수급안정 선도기업 / 일반기업 | 하나만 선택 |
| 약제별 가산 — 일반 | 오리지널·자료제출의약품 / 개량신약·개량신약복합제 / 생물의약품 | 체크 항목; 선택 없는 상태 허용 |
| 약제별 가산 — 수급안정 | 원료직접생산의약품 / 국산원료 사용 국가필수의약품 / 직접 생산 항생주사제·소아의약품 | 체크 항목; 선택 없는 상태 허용 |
| 동일제제 품목 수 | 14개 이상 / 14개 미만 | 하나만 선택 |

기업 구분과 품목 수는 서로 배타적인 선택으로 구성한다. 약제 가산 조건은 해당 여부를 기록하되 중복 체크 가능 범위와 실제 중복 적용 여부는 규정 확인 후 정한다. 서로 다른 자격의 가산률을 단순 합산하지 않는다.

**확인이 필요한 부분:** 각 조건의 실제 약가 산정률, 중복 적용·우선순위, 적용 시점 및 오리지널 현재 약가를 산정 기준금액으로 그대로 사용할 수 있는 조건. 확인 전에는 오리지널 약가를 우리 제품 약가로 간주하지 않는다. 기존의 예상 보험약가 직접 입력을 작은 보조 항목으로 유지하여 원가율 계산에 사용할 수 있도록 제안한다. 적용 규정이 확인되면 예상 보험약가 결과와 근거를 표시한다.

### 원료표

| 구분 | 원료명 | 제조원·공급처 | 실제 투입량 (mg/T) | 구매단가 | 단가 단위 | 배치당 비용 (원) | 1T당 비용 (원/T) |
| --- | --- | --- | --- | --- | --- | --- | --- |
| API / 부형제 | 입력 | 입력 | 입력 | 입력 | 원/g · 원/kg · 달러/g · 달러/kg | 자동 계산 | 자동 계산 |

단가 단위 하나에 통화와 질량 단위를 함께 담아 중복 선택을 줄인다. 기존 등급·규격, 계산 기준, 행별 환율, 견적일, 메모, 적용 원화 단가 칸은 화면에서 제거한다. API·부형제 행 추가·삭제와 복사·붙여넣기는 유지한다.

표 바로 아래에는 다음 네 합계를 표시한다.

- 배치당 API 비용
- 배치당 부형제 비용
- 1T당 API 비용
- 1T당 부형제 비용

### 고정비

| 항목 | 입력 | 자동 표시 |
| --- | --- | --- |
| 포자재비 | 배치 전체 포자재비(원/배치) | 1T당 포자재비(원/T) |
| 공수비 | 배치 전체 공수비(원/배치) | 1T당 공수비(원/T) |

기존 단위제형·포장·배치 방식 선택과 별도 환산 수량 입력은 제거한다.

## 계산 기준

`N = 배치사이즈`, `Y = 수율(%) ÷ 100`, `m = 실제 투입량(mg/T)`로 둔다.

- 원화/g: 배치당 원료비 = `m × N × 구매단가 ÷ 1,000`
- 원화/kg: 배치당 원료비 = `m × N × 구매단가 ÷ 1,000,000`
- 달러 단가는 위 식의 구매단가에 `달러 단가 × 공통 환율`을 사용한다.
- 원료별 1T 비용 = `원료별 배치당 비용 ÷ (N × Y)`
- 1T당 포자재비 = `배치 전체 포자재비 ÷ (N × Y)`
- 1T당 공수비 = `배치 전체 공수비 ÷ (N × Y)`
- 1T당 제조원가 = `1T당 API 비용 + 1T당 부형제 비용 + 1T당 포자재비 + 1T당 공수비`
- 제조원가율 = `1T당 제조원가 ÷ 우리 제품 예상 보험약가 × 100`

수율은 단위 비용의 분모에서 한 번만 적용한다. 배치 총비용 자체를 다시 수율로 나누지 않는다. 손실 전 기준의 같은 한 배치에 쓰는 원료·고정비 총액은 수율 변화만으로 증액되지 않고, 1T당 비용이 높아진다. 중간값은 표시를 위해 반올림하지 않는다.

예: 배치사이즈 100,000T, API 20mg/T, 1,000,000원/kg이면 API 배치비는 2,000,000원이다. 수율 100%일 때 20원/T, 수율 80%일 때 25원/T다. 같은 배치 포자재비 300,000원은 100%일 때 3원/T, 80%일 때 3.75원/T다.

## 결과·시나리오 비교 페이지

- 위쪽: 선택 시나리오의 1T당 제조원가, 예상 보험약가, 원가율, 목표 원가율, 목표와의 차이, 필요 절감액.
- 가운데: API·부형제·포자재·공수 비용 구성표와 간단한 차트.
- 아래쪽: 여러 시나리오를 열로 놓고 주요 입력과 결과를 행으로 놓은 비교표.
- 시나리오 선택·복제·이름 변경은 두 페이지에서 공통으로 사용할 수 있도록 상단에 유지한다.
- 비교 항목에는 배치사이즈·수율·환율·약가 조건·원료와 공급처·단가·배치 및 1T 비용을 포함한다.

원가율의 분모는 우리 제품의 예상 보험약가다. 오리지널 약가로 조용히 대체하지 않는다. 미입력·잘못된 값은 해당 위치에 표시하고 계산 가능한 부분만 보여준다.

## 구현 순서 및 검증 예정

1. 배치사이즈·공통 수율·공통 환율과 네 단가 단위의 계산을 구현한다.
2. 입력 한 페이지 / 결과·비교 한 페이지로 화면을 개편한다.
3. 확인된 규정에 따라 약가 조건과 산정 결과를 연결한다.
4. JSON 형식 버전을 올리고 기존 파일의 원본과 과거 정보를 보존하는 이전 절차를 준비한다. 배치사이즈, 서로 다른 과거 환율, 개당 구매 원료 등은 임의로 변환하지 않는다.
5. g/kg 환산 일치, USD 행에만 환율 적용, 수율 100%·80%, 고정비 수율 적용, 행과 합계 일치, 원본 시나리오 유지, 저장 왕복 및 화면 테스트를 실행한다.

원가 계산·원료 입력·고정비·결과 및 시나리오 비교는 웹 버전으로 구현했다. 약가 조건은 저장할 수 있지만 확인되지 않은 자동 산정률은 적용하지 않는다. 기존 데스크톱 프로그램은 보존하며, 웹의 계산 모델과 JSON 형식은 기존 데스크톱 형식과 구분한다.
