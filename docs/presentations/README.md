16:9 화면비의 5장 자료입니다. 현재 프로그램을 직접 실행해 캡처한 입력·결과 화면과 짧은 사용 설명을 함께 담았습니다. 설명 문구는 PowerPoint에서 편집할 수 있으며, 캡처 화면은 파일 안에 포함되어 있습니다.

1. 제품정보·생산조건·약가 입력
2. 원료 입력표·배치 전체 고정비
3. 계산 결과·비용 구성 그래프
4. 시나리오 비교·복제·정렬·출력·JSON 저장
5. SF 판매수량 입력·연간 및 연차별 누적 예상이익

2026-10-23 현행 웹 버전을 기준으로 작성했습니다. 화면과 금액은 프로그램의 가상 예제를 사용했습니다. 실제 제품·견적 데이터는 포함하지 않습니다. 예상 약가의 일반·수급안정 가산은 간편 가정이며, 예상이익은 판관비·개발비·세금을 제외한 제조원가 기준입니다.
