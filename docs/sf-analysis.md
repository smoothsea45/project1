# SF·이익 분석 안내

판매 예측(Sales Forecast, SF)을 **금액**으로 입력해 현재 시나리오의 제조원가와 연차별 약가에 연결합니다. 판매수량은 입력하지 않습니다. 프로그램은 브라우저 안에서 계산하며 SF를 서버나 외부 API로 전송하지 않습니다.

## 바로 사용하기

1. 화면 위쪽에서 **SF·이익 분석 사용**을 체크합니다.
2. **입력** 탭에서 분석기간을 선택하고 공통 SF를 입력합니다. 기본기간은 8년, 선택범위는 1~10년이며 금액 단위는 **백만원**입니다. `1,000`은 10억원입니다.
3. 시나리오별 SF가 다르면 해당 시나리오를 선택하고 **현재 시나리오에 별도 SF 사용**을 체크해 연차별 금액을 입력합니다.
4. **시나리오 비교** 옆의 **이익 분석** 탭에서 그래프와 비교표를 확인합니다. **프로젝트 저장**으로 원가 입력과 SF를 하나의 JSON 파일에 저장합니다.

## 계산 기준

| 항목 | 계산식 |
| --- | --- |
| 해당 연차 제조원가율 | 현재 시나리오 제조원가/T ÷ 해당 연차 약가 |
| 예상 제조원가 금액 | 해당 연차 SF × 해당 연차 제조원가율 |
| 예상이익 | 해당 연차 SF − 예상 제조원가 금액 |
| 누적 예상이익 | 1년차부터 해당 연차까지 예상이익 합계 |
| 기준 대비 이익 차이 | 해당 시나리오 누적 예상이익 − 첫 시나리오 누적 예상이익 |

예를 들어 SF `1,000`백만원(10억원), 제조원가 90원/T, 약가 300원/T이면 원가율은 30%입니다. 예상 제조원가는 300백만원(3억원), 예상이익은 700백만원(7억원)입니다.

이 금액은 **제조원가만 반영한 예상이익**입니다. 판관비·개발비·세금을 차감한 순이익은 아닙니다. SF가 회사의 판매금액이더라도 원가율의 분모에는 보험약가를 사용합니다. 실제 납품가·할인율에 따른 원가율을 별도로 추정하지 않는 간편 모델입니다.

현재 시나리오의 제조원가/T는 전 기간에 동일하게 적용합니다. 원료단가·환율·수율·배치 비용을 변경하면 전 기간이 다시 계산됩니다. 향후 물가·생산량·가동률에 따른 원가 변동은 자동 적용하지 않습니다. 직접 입력 모드에서는 입력 약가를 전 기간에 유지하고, 예상 약가 계산 모드에서는 각 연차 약가를 사용합니다. 기존 비교 탭에서 미리보기로 선택한 연차와 무관하게 1년차부터 순서대로 계산합니다.

## 공통 SF와 시나리오별 SF

기본적으로 공통 SF를 모든 시나리오에 적용합니다. 시나리오별 별도 SF를 켜면 **값을 입력한 연도만** 공통 SF 대신 사용합니다.

| 별도 SF 입력 | 적용 금액 |
| --- | --- |
| 별도 SF 사용 꺼짐 | 공통 SF |
| 별도 SF 사용 켜짐 + 빈칸 | 공통 SF |
| 별도 SF 사용 켜짐 + `0` | 0원, 해당 연도 판매 없음 |
| 별도 SF 사용 켜짐 + 양수 | 입력한 별도 SF |

SF 금액에는 음수를 허용하지 않습니다. 기능을 꺼도 SF 입력값은 유지되며, 분석기간을 줄여도 보이지 않는 연도의 값은 삭제하지 않습니다. 공통·별도 SF는 각각 최대 10년을 저장합니다. 시나리오를 복제하면 별도 SF 설정과 금액도 독립적으로 복제됩니다.

## 그래프와 비교표

- **연차별 예상이익:** 같은 연도에서 시나리오별 막대를 나란히 표시합니다.
- **누적 예상이익:** 1년차부터 누적한 이익을 시나리오별 선으로 표시합니다.
- **시나리오별 누적 비교:** 누적 SF·예상 제조원가·예상이익과 기준 시나리오 대비 이익 차이를 보여줍니다.
- **연차별 계산 내역:** SF·약가·원가율·예상 제조원가·예상이익을 숫자로 확인합니다.

시나리오 색은 두 그래프에서 일치하며 비교하는 시나리오들은 같은 축을 사용합니다. 원가율이 100%를 넘으면 예상이익은 음수이며 그래프의 0 아래에 표시합니다. 비교의 기준은 **현재 탭 순서의 첫 시나리오**입니다. 시나리오 탭을 드래그해 순서를 바꾸면 비교표의 기준도 바뀝니다.

SF가 비었거나 잘못되면 미입력·오류로 표시합니다. 약가가 없거나 0, 또는 필수 원가 입력이 미완성인 연도는 이익을 계산할 수 없습니다. 이때 0원 이익으로 대신하지 않습니다. 누적 그래프는 미완성 연도부터 이어 그리지 않고, 분석기간 중 미완성 연도가 있으면 최종 원가·이익 합계와 기준 대비 차이도 확정값으로 표시하지 않습니다. `0`을 직접 입력한 SF는 미입력과 구분하되, 이익 계산에는 유효한 약가와 제조원가가 필요합니다.

## 파일과 오프라인 사용

SF 사용 여부, 분석기간, 공통 SF와 시나리오별 SF는 **버전 3 웹 프로젝트 JSON**에 저장됩니다. 기존 버전 1·2 웹 프로젝트를 열면 원가·약가·시나리오 입력을 보존하고 SF는 꺼진 상태로 시작합니다. 버전 3으로 저장한 파일은 예전 버전 2 프로그램에서 열 수 없으므로 예전 프로그램도 사용하는 경우 기존 원본을 별도로 보관하세요.

브라우저 초안도 해당 브라우저의 로컬 저장소에 보관합니다. 다른 PC로 옮기거나 보관하려면 프로젝트 JSON을 저장하세요. SF 값을 GitHub에 업로드하는 기능은 없습니다.

인터넷 없이 실행할 때는 `web/index.html`만 복사하지 말고 **`forecast.js`·`profit-view.js`와 `vendor`를 포함한 `web` 폴더 전체**를 복사합니다. Python·npm·서버 설치는 필요하지 않습니다.
