# 첫 버전 구현 계획

## 구조

- `pharma_cost/models.py`: 제품, 원료, 비용, 약가 정보, 시나리오, 프로젝트 데이터.
- `pharma_cost/calculation.py`, `pricing.py`: Decimal 기반 비용 계산과 사용자 입력 약가. Qt와 파일 입출력에 의존하지 않음.
- `pharma_cost/storage.py`, `examples.py`: 버전 있는 JSON 파일, 원자적 저장, 가상 예제.
- `pharma_cost/ui/`: 한국어 PySide6 화면, 원료 표, 결과·차트, 시나리오 비교.
- `tests/`: 요구된 계산 사례, 파일 왕복 및 잘못된 파일, 실제 Qt 위젯 동작.
- Windows 전용 PyInstaller 폴더 배포 설정과 사용 안내.

## 진행 및 검증

1. 데이터 모델·계산 검증과 JSON 저장 구현.
2. 입력 변경 즉시 재계산, 시나리오 복제·비교, 프로젝트 파일 동작 구현.
3. 계산/저장 테스트와 offscreen Qt 화면 테스트 실행.
4. 개발 실행·Windows 빌드·오프라인 사용 절차 기록.

## 명시적 가정

- 모든 금액은 원/정 또는 원/캡슐이며 API/부형제의 결과 합계는 이론 비용이다. 차트의 원료 비용에는 전체 수율을 적용한다.
- 수율은 전체 원재료비에만 적용하고 포장재비·공수비에는 적용하지 않는다.
- 표시 함량은 설명용 문자열이며 실제 투입량을 계산에 사용한다. 염·수화물·역가 보정은 하지 않는다.
- 원화 직접 입력과 외화 환산을 행별로 명시적으로 선택한다. 통화는 표시 정보이며 환율은 사용자가 입력하는 원/외화 1단위이다.
- 약가는 사용자 입력값만 사용한다. 기록한 허가·약가 관련 조건은 계산에 반영하지 않는다.
- 공통 제품정보를 여러 시나리오가 공유하며 원료·약가·비용·수율은 시나리오별로 독립 보관한다.
- JSON에는 Decimal을 십진 문자열로 저장한다. 중간 계산에서 화면 반올림을 적용하지 않는다.
- Windows 실행파일은 Windows에서 빌드해야 한다. Linux 검증으로 Windows 빌드를 완료했다고 간주하지 않는다.
