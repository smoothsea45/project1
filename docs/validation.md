## 약제별 간편 가산과 비교 연차 미리보기 검증 (2026-10-15)

## 개량신약 4년·비교 공통 축·겹친 원가 막대 검증 (2026-10-15)

- 개량신약은 오리지널 기준약가의 70%, 개량신약복합제는 68%를 각각 1~4년차에 적용하고 5년차부터 기본요건별 약가로 전환한다. 두 기본요건·한 요건·미충족에서 4년차와 5년차의 경계를 검증했다.
- Node 계산·파일 테스트 **174개 통과**. 브라우저는 변경한 약가·비교 테스트 **31개**와 나머지 기존 화면·그래프·인쇄 테스트 **94개**가 모두 통과해 총 **125개**를 검증했다.
- 비교 그래프의 원가 수평선을 없애고 연차마다 넓은 약가 막대 앞에 좁은 제조원가 막대를 겹쳤다. 실제 폭·가로 중심·하단 위치와 입력 금액에 비례하는 높이를 검사했다. 원가가 약가보다 커도 약가 막대 양옆과 더 높은 원가 막대가 구분된다.
