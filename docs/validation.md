# 첫 버전 검증 기록

검증 환경: Linux x86_64, Python 3.12.14, PySide6 6.8.3. 화면은 실제 Qt 위젯을 `offscreen` 플랫폼에서 생성하여 검증했다.

```bash
QT_QPA_PLATFORM=offscreen XDG_CACHE_HOME=/tmp/pharma-cost-cache .venv/bin/python -m pytest
```

결과: **113 passed**.

추가 확인:

- 가상 예제 기본안: API 40원 + 부형제 10원 + 포장재비 10원 + 공수비 20원 = **80원/정**, 약가 300원 대비 **26.67%** (표시값).
- 가상 예제 절감안: **60원/정**, 약가 300원 대비 **20%**, 목표 달성.
- 편집 가능한 설치(`pip install --editable .`)와 설치된 모듈의 프로그램 창 시작·정상 종료를 확인했다.
- `pip check`: 의존성 충돌 없음.
- 제품·약가, 원료, 비용, 결과·차트, 비교 탭을 offscreen 이미지로 렌더링하여 표시를 확인했다.

Windows 배포는 **설정 및 절차 준비** 상태다. 현재 환경에서 Windows `.exe`를 빌드하거나 Python 없는 Windows PC에서 실행하지 않았다. 실제 Windows 빌드 및 오프라인 실행 검증은 [Windows 배포 안내](windows-distribution.md)에 따라 수행해야 한다.

약가 자동 산정률은 구현하거나 검증하지 않았다. 첫 버전의 계산은 사용자 입력 약가만 사용한다.
