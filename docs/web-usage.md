# 웹 버전 사용 안내

브라우저에서 사용하는 의약품 제조원가율 시뮬레이터입니다. Python이나 프로그램 설치 없이 Edge·Chrome 등 최신 브라우저에서 실행합니다. 입력값 계산과 JSON 파일 처리는 내 컴퓨터의 브라우저에서 이루어지며 외부 API나 서버로 입력값을 전송하지 않습니다.

## 인터넷 없이 사용하기

1. GitHub 저장소의 **Code → Download ZIP**으로 파일 전체를 받습니다.
2. ZIP 파일을 폴더에 모두 풉니다.
3. 풀린 폴더 안의 **web → index.html**을 더블클릭합니다. 저장소 루트의 `index.html`을 열어도 같은 화면으로 이동합니다.
4. 이후에는 인터넷 연결 없이 사용할 수 있습니다. `forecast.js`·`profit-view.js`를 포함해 `web` 폴더 안의 JavaScript·CSS·`vendor` 파일을 함께 유지하세요. `index.html` 파일만 복사하면 실행되지 않습니다.

인터넷이 되는 PC에서 받은 전체 폴더를 회사 PC로 전달해도 됩니다. 개발 도구나 npm을 설치할 필요가 없습니다.

## 입력하기

**입력** 페이지에서 다음 순서로 입력합니다.

1. 현재 시나리오의 제품명과 비고를 적습니다. 함량·제형 등 필요한 설명은 비고에 기록합니다. 두 항목은 시나리오마다 독립적으로 저장되고, 탭을 바꾸면 해당 시나리오 값으로 전환됩니다. 복제하면 두 항목도 복사되며 이후 수정은 원본에 영향을 주지 않습니다.
2. **배치사이즈**는 손실 발생 전 기준 수량을 입력합니다. 화면의 `T`는 계산하는 한 단위제형을 뜻합니다.
3. 제조수율을 입력합니다. 기본값은 100%이고, 0% 초과 100% 이하만 사용할 수 있습니다. 이 웹 모델은 원료·포자재·공수의 단위 비용 모두에 같은 수율을 적용합니다.
4. **포장형태**를 입력합니다. 예: `PTP 10T × 3`, `병포장 30T`. 시나리오별로 저장·복제·비교되는 자유텍스트 항목입니다. 포자재비 계산에는 직접 입력한 배치 전체 금액을 사용합니다.
5. 달러 구매단가를 사용할 경우 **달러 환율(원/USD)**을 입력합니다. 같은 시나리오 안의 달러 단가 원료에 공통 적용됩니다. 환율은 자동 조회하지 않습니다.
6. **약가 조건** 제목 옆에서 **직접 입력 / 예상 약가 계산**을 선택합니다. 직접 입력은 오른쪽 우리 제품 약가를 사용합니다. 예상 계산은 회사·품목·시장 정보를 입력하고 아래 10년 그래프에서 적용할 연차를 선택합니다. 자세한 조건은 다음 절을 참고하세요.
7. **API 추가**, **부형제 추가**로 원료 행을 넣고 원료명, 공급처, 실제 투입량(mg/T), 구매단가와 단가 단위를 입력합니다. 단가 단위는 **원/g, 원/kg, 달러/g, 달러/kg** 네 가지입니다. API는 여러 개 추가할 수 있습니다. 선택 행 삭제는 왼쪽 체크박스로 행을 고른 뒤 사용합니다.
8. 포자재비와 공수비는 **배치 전체 금액**을 원으로 입력합니다. 기존 자료가 단위 비용이면 먼저 해당 배치 전체 금액으로 환산해 입력합니다.

숫자를 바꾸면 원료별 배치 비용과 1T당 비용, 결과가 바로 갱신됩니다. 필수 입력이 빠지거나 잘못된 경우에는 해당 입력과 안내를 확인하세요. 금액·투입량은 0 이상, 배치사이즈와 환율은 양수여야 합니다. 약가가 없거나 0이면 제조원가는 표시하고 원가율은 계산 불가로 표시합니다.

큰 숫자는 입력 중에도 `100,000`, `1,000,000`처럼 천 단위 쉼표가 표시됩니다. 쉼표는 표시용이며 계산값과 소수 자릿수는 유지합니다. 잘못된 `1,2` 같은 입력은 임의로 고치지 않고 오류를 표시합니다.

염·수화물 환산과 함량·역가 보정은 하지 않습니다. 표시 함량과 실제 투입량이 다르다면 보정한 실제 투입량을 사용자가 입력합니다. 무료로 제공되는 원료·비용은 0으로 입력할 수 있습니다.

## 약가 조건 사용하기

### 직접 입력

오른쪽 **우리 제품 약가**에 입력한 금액을 원가율 계산에 사용합니다. 약가 조건 안에서는 모드 전환과 이 금액만 조작할 수 있습니다. 기업·약제별 가산, 기본 산정요건, 품목 수, 등재일, 오리지널 기준약가는 실제로 비활성화되어 클릭·키보드로 수정할 수 없습니다. **원료·배치·수율·환율·고정비용 입력은 계속 사용할 수 있습니다.** 입력 탭의 10년 예상 약가 그래프는 숨깁니다.

오리지널 가격과 가산 조건이 비어 있어도 관계없습니다. 직접 입력 300원 → 예상 계산 결과 450원 → 직접 입력으로 되돌아오면 **300원이 복원**됩니다. 자동 결과가 수동 금액을 덮어쓰지 않습니다. 기존 가산 종료 후 약가 입력은 사용하지 않습니다.

### 예상 약가 계산: 간편 가정 모델

일반 또는 수급안정 가산을 선택하면 **사용자가 지정한 비율·기간**으로 계산합니다. 법정 가산 자격이나 실제 급여 결정금액을 검증하는 모델이 아닙니다. 화면에 **간편 가정 · 오리지널 기준약가 대비**라고 표시합니다.

1. **약제별 일반가산**은 해당 없음·자료제출의약품·개량신약·개량신약복합제·기타·생물의약품 중 하나를 선택합니다.
2. **수급안정 가산**은 별도 그룹에서 해당 없음·원료직접생산의약품·국산 원료 사용 국가필수의약품·직접 생산 항생주사제/소아용의약품 중 하나를 선택합니다.
3. **오리지널 기준약가**와 **우리 제품 예상 등재일**을 입력합니다. 별도 개발목표제품 금액·실제 기산일·세부 산정유형은 입력하지 않습니다.
4. 비생물 일반가산에서는 가산 종료 후 가격에 사용할 **기본 산정요건** 두 개를 각각 선택합니다. 두 개 충족은 오리지널의 45%, 한 개는 36%, 모두 미충족은 29%라는 가정입니다. 법정 면제·충족 간주를 반영할 때는 해당 체크에 표시합니다. 생물은 종료 후 70%로 고정하므로 이 체크가 필요하지 않습니다.

모든 간편 비율은 **오리지널 기준약가에 직접 곱합니다.** `1년 + 3년` 등 기간은 자동으로 합치고 별도 연장 선택을 받지 않습니다.

| 선택 | 가산 일정 | 종료 후 |
|---|---|---|
| 자료제출의약품 | 1년차 70% → 2~4년차 60% | 5~10년차 기본요건별 45/36/29% |
| 개량신약 | 1~4년차 70% (1년 + 3년) | 5~10년차 기본요건별 45/36/29% |
| 개량신약복합제 | 1~4년차 68% (1년 + 3년) | 5~10년차 기본요건별 45/36/29% |
| 기타 | 1~4년차 60% | 5~10년차 기본요건별 45/36/29% |
| 생물의약품 | 1~5년차 80% | 6~10년차 70% |
| 수급안정 3종 모두 | 1~5년차 68% + 6~10년차 68% | 10년 표시 범위 안에서는 종료하지 않음 |

수급안정의 뒤 5년은 **연장요건 충족 가정**으로 자동 표시합니다. 일반가산과 수급안정을 함께 선택하면 **수급안정 일정 하나를 우선 적용**합니다. 기업·일반·수급안정 비율을 더하거나 기간을 이어 붙이지 않습니다. 간편 일정에는 기업가산이나 14개 이상 추가 감액을 적용하지 않습니다.

예전의 개발목표제품 상한금액·개량신약 인정·가산 기산일·자격·연장 체크 등 상세 조건은 화면에서 제거했으며, 기존 파일의 값은 보존하되 간편 계산에서 사용하지 않습니다. 수급안정은 기존 세부요건 체크와 무관하게 선택한 68% 일정을 적용합니다. 따라서 체크가 없다는 이유로 자동 계산을 차단하지 않습니다.

### 일반·수급안정 모두 해당 없음: 기존 일반 제네릭

이 경우에는 간편 일정 대신 기존 일반 제네릭 계산을 유지합니다. 특허 만료 후 **최초 제네릭 등재군**에 참여하며 입력 등재일과 가산 기산일이 같다는 범위입니다. 후속 진입그룹·과거 계단식 산정 이력은 계산하지 않습니다.

- 기본 산정요건 두 개 충족은 오리지널 기준약가의 **45%**, 하나는 **36%**, 모두 미충족은 **29%**입니다.
- 기업은 일반·혁신형·준혁신형·수급안정 선도기업 중 하나를 선택합니다. 두 요건과 기업가산 품목 요건을 충족하면 혁신형은 기본약가 × 60/45, 준혁신형·수급안정 선도기업은 × 50/45입니다. 기본 1년 또는 국내생산 연장요건 충족 시 총 4년입니다.
- API가 복수 행이면 일반 단일제 여부를 확정할 수 없다고 보고 기업가산을 제외하며 사유를 표시합니다. 같은 API를 여러 공급처 행으로 나눈 경우도 이 제한이 적용됩니다.
- 동일제제 품목 수는 오리지널과 우리 제품을 포함합니다. **정확히 14개도 14개 이상 유발**입니다. 가산 종료 후 기본약가의 85%, 가산이 없으면 1년 유예 후 85%를 적용합니다. 14개 미만은 이 감액이 없습니다.
- 각 약가 단계는 원 단위 반올림합니다. 예: 450원 × 85% = 382.5원 → 383원.

이 분기의 규정 기준은 사용자가 지정한 **2026-08-01**입니다. 지정된 공식 별표 PDF 산식은 확인했지만, 규정 본문이 HTTP 403으로 차단되어 시행일·부칙은 독립 확인하지 못했습니다. 간편 일정까지 공식 규정에 따른 계산이라고 해석하지 않습니다. 상세 조사 기록은 [약가 참고 기록](pricing-reference.md)에 있습니다.

### 입력 탭의 10년 그래프와 적용 연차

예상 계산 모드에서는 약가 조건 아래에 **세로 막대 10개**가 나타납니다. X축은 등재일부터의 1~10년차와 시작 연도, Y축은 0원부터의 약가입니다. 금액·툴팁의 비율·적용기간·가정·상단 요약이 조건 변경에 맞춰 갱신됩니다.

등재일 `2027-09-01`의 1년차는 `2027-09-01~2028-08-31`, 2년차는 `2028-09-01~2029-08-31`입니다. 연말에 자르거나 365일을 곱하지 않고 달력 기준으로 계산합니다.

모드 전환 시 **1년차**를 기본 적용합니다. 막대를 클릭하거나 키보드로 선택하면 그 연차의 약가가 오른쪽 적용 약가·선택 연차와 결과 탭의 원가율에 반영됩니다. 수동 원본은 그대로 보관합니다. 필수 가격·날짜가 비거나 잘못되면 이전 금액과 그래프를 남기지 않고 안내합니다. 제조원가는 가능하면 계속 계산하고, 유효한 약가가 없으면 원가율은 `계산 불가`입니다.

실거래가 조정·사용량-약가 연동·기등재 재평가 등 별도 사후 조정과 미래의 자격·제도 변경은 예측하지 않습니다.

## 계산 기준

이 웹 버전은 **배치 전체 비용**을 기준으로 계산합니다. 배치사이즈를 `N`, 수율을 `Y`라고 할 때 80%는 `0.8`입니다.

| 항목 | 계산식 |
| --- | --- |
| 원료별 배치 비용: 원/kg | 실제 투입량(mg/T) × N × 단가(원/kg) ÷ 1,000,000 |
| 원료별 배치 비용: 원/g | 실제 투입량(mg/T) × N × 단가(원/g) ÷ 1,000 |
| 달러 원료 단가 | 달러 단가 × 공통 환율(원/USD) |
| 원료별 1T당 비용 | 원료별 배치 비용 ÷ (N × Y) |
| 1T당 포자재비·공수비 | 각 배치 전체 비용 ÷ (N × Y) |
| 제조원가 | 1T당 API + 부형제 + 포자재비 + 공수비 |
| 보험약가 대비 원가율 | 제조원가 ÷ 우리 제품 예상 보험약가 × 100 |

예를 들어 API 20mg/T, 1,000,000원/kg, 배치사이즈 100,000T이면 원료의 배치 비용은 2,000,000원입니다. 수율 100%에서는 20원/T, 수율 80%에서는 25원/T입니다. 배치 포자재비가 1,000,000원이면 같은 조건에서 각각 10원/T, 12.5원/T입니다.

제조원가 내부 숫자는 함께 배포된 Decimal 라이브러리로 계산하며 화면 표시에서만 반올림합니다. 예상 약가는 간편 비율 계산과 일반 제네릭 계산 모두 원 단위로 반올림하되, 법정 단계별 산정이라는 설명은 일반 제네릭 분기에만 해당합니다. **약가 표시는 원 단위 정수**로 통일하며, 입력 탭의 예상 약가·10년 그래프·요약, 결과 카드·도넛 기준 약가, 비교표·8년 그래프와 툴팁에 동일하게 적용합니다. **입력·결과 탭의 비용**은 소수 둘째 자리, **비교표의 원/T 비용**은 소수 첫째 자리로 표시합니다. 비교표 API 단가·배치 금액은 정수, 비율은 첫째 자리이며, 가격과 비용을 함께 사용하는 비교 공통 축은 기존 소수 첫째 자리를 유지합니다. 0이 아닌 매우 작은 비율은 `0.0%`로 오해하지 않도록 `<0.1%`로 표시합니다. 표시 반올림은 직접 입력값·JSON·내부 계산값을 바꾸지 않으며, 비용 구성과 연차 그래프도 실제 계산값으로 그립니다. 제조원가율 100% 초과도 그대로 표시합니다. 보험약가 대비 원가율은 실제 판매이익률과 다릅니다.

## 결과와 시나리오 비교

상단 버튼으로 **입력 / 결과 / 시나리오 비교** 페이지를 이동합니다. 선택된 탭은 진한 색으로 표시합니다. 키보드 방향키로 탭을 바꿀 수도 있습니다.

**결과** 페이지는 왼쪽에 비용 구성 그래프, 오른쪽에 **약가 → 제조원가 → 원가율** 카드를 세로로 배치합니다. **원가율** 카드를 진한 색으로 강조합니다. 작은 화면에서는 그래프 다음에 숫자 카드를 배치합니다. 약가 계산 근거 영역은 표시하지 않습니다. 그래프의 도넛은 보험약가를 기준으로 API·부형제·포장재비·공수비와 회색 차액을 표시합니다. 중앙에는 약가 대비 제조원가율과 제조원가를 표시합니다. 세로 누적 막대와 항목별 비율은 총 제조원가를 기준으로 하며, 아래에 API와 부형제를 합한 원재료비와 비율을 표시합니다. 입력값과 시나리오를 바꾸면 두 그래프가 함께 갱신됩니다.

제조원가가 약가를 초과하면 중앙에 실제 원가율을 표시하고, 도넛 구간은 제조원가 기준으로 전환했음을 안내합니다. 이 경우 음수 차액을 회색 구간으로 그리지 않습니다. 약가가 없거나 0이면 도넛 원가율은 계산 불가이며, 제조원가가 0이면 오른쪽 구성비는 `—`로 표시합니다. 필수 비용이 미완성이면 확정된 구성비를 표시하지 않습니다.

가산 종료 후 약가 등 기존 입력 데이터는 호환성을 위해 보존하지만 두 모드의 계산에는 사용하지 않습니다. 결과 페이지에는 현재 모드·선택 연차의 약가를 사용하며, 약가 계산 근거와 가산 종료 후 원가율을 별도 카드로 표시하지 않습니다. 목표 제조원가율 입력과 관련 결과 표시는 제거했습니다.

위쪽의 **현재 입력 복제**를 누르면 현재 시나리오의 독립 복사본이 생깁니다. 한 프로젝트에는 **최대 4개**까지 만들 수 있으며, 4개가 되면 복제 버튼을 사용할 수 없습니다. **이름 변경**으로 구분하고 처방, 공급처·단가·환율·배치사이즈·수율·포장형태·약가·고정 비용을 바꿔 보세요. 복제본을 수정해도 원본은 유지됩니다. 위쪽의 **보라색 시나리오 탭**을 클릭하여 편집 대상을 바꿉니다. 아래 작업 페이지 탭은 청록색으로 구분합니다. 선택된 탭에 포커스를 두고 방향키·Home·End로 이동할 수도 있습니다.

**시나리오 탭을 드래그**하여 순서를 바꿀 수 있습니다. 옮길 위치의 보라색 선을 확인한 뒤 놓으세요. 탭의 번호, 비교표의 열과 출력 순서가 함께 바뀌고, 현재 선택한 시나리오와 각 입력값·비교 연차는 유지됩니다. 탭 바깥에 놓거나 Esc로 취소하면 순서를 바꾸지 않습니다. 키보드는 탭에 포커스를 두고 **Alt+Shift+←/→**로 한 칸씩 옮깁니다. 바뀐 순서는 브라우저 초안과 프로젝트 JSON에 저장되며 다시 열어도 유지됩니다.

비교 항목은 **시나리오명 → 배치사이즈·수율·포장형태 → API 제조원·단가 → 약가 → 제조원가·원가율 → 비용 구성 그래프 → 연차별 약가·제조원가 그래프 → API 비용 → 부형제 비용 → 포자재 비용 → 공수비용** 순서입니다. 비용별로 한 행에 **배치당(원) / 1T당(원/T)** 두 열을 나란히 표시하며, 이 단위 제목은 API 비용 바로 위에 표시합니다. 복합제는 API별 제조원과 단가를 원료명과 함께 구분합니다. API 이름 칸을 넓혀 긴 성분명의 줄바꿈을 줄였습니다. 각 시나리오의 그래프는 그 시나리오의 실제 계산값을 사용합니다.

API 단가는 입력 단위와 관계없이 **원/kg과 달러/kg**을 함께 표시합니다. g 기준 단가는 1,000배 하여 kg 기준으로 바꾸고, 원화→달러는 해당 시나리오 환율로 나누며 달러→원화는 곱합니다. 환율이 없거나 유효하지 않으면 입력 통화의 kg 단가는 유지하고 상대 통화에 **환율 필요**를 표시합니다. 입력값이나 저장값을 변환해서 덮어쓰지 않습니다.

비용 구성 아래 **1~8년차 누적 막대그래프**는 다음 기준을 사용합니다. 입력 탭의 10년 계산은 유지하며, 비교 그래프는 높이를 늘려 약가와 원가율을 구분합니다.

- 제조원가 ≤ 약가: 아래 제조원가 + 위 약가 차액으로 쌓으며 전체 높이는 약가입니다.
- 제조원가 > 약가: 아래 약가 범위 + 위 빨간 원가 초과분으로 쌓으며 전체 높이는 실제 제조원가입니다. 음수 차액을 그리거나 제조원가와 약가를 중복 합산하지 않습니다.
- 원가가 미완성이면 중립색의 약가 막대만 표시합니다. 원가를 0으로 대신하지 않습니다.

연차별 약가 차액은 위 비용 구성 그래프와 구분되는 보라·분홍 계열을 사용합니다. 가산·가산 종료 후·연장 가정에 따라 실제 막대와 같은 색의 범례를 표시하며, 색이 여러 개이면 `약가 차액 (1~4년)`처럼 해당 연차 구간도 함께 표시합니다.

막대 위에는 **약가 금액을 소수점 없이 원 단위**로 표시합니다. **제조원가율은 아래 갈색 제조원가 구간 안**에 소수 첫째 자리로 표시합니다. 갈색 구간이 매우 얇거나 0이면 원래 막대 높이를 유지하고 기준선 부근의 작은 배지로 구분합니다. 약가 0 또는 원가 미완성은 **계산불가**입니다. 1,000% 이상은 작은 칸에서도 읽도록 `5.0e3%`처럼 짧게 표시하고, 툴팁에는 `5,000.0%`처럼 전체 비율을 보여줍니다. 툴팁의 약가는 정수, 원가는 소수 첫째 자리입니다. 약가 차액은 판매이익을 뜻하지 않습니다.

비교하는 모든 시나리오의 **1~8년차 약가와 제조원가 전체의 최대값 × 1.25**로 공통 축을 정해 금액 라벨에 여유를 둡니다. 같은 금액은 같은 높이이며 초과 원가도 잘리지 않습니다. 도넛 왼쪽 위에는 선택 연차 배지가 표시되고, 연차 클릭 시 해당 시나리오의 배지만 바뀝니다. 직접 입력 모드는 비교 기간 동안 입력 가격을 유지하는 가정입니다.

비교 그래프의 선택은 **시나리오별 미리보기**입니다. 처음에는 각각 1년차이며, 막대를 선택하면 **해당 시나리오 열의 약가·원가율·도넛**만 함께 바뀝니다. 제조원가는 연차 선택으로 바뀌지 않습니다. 다른 시나리오의 선택과 입력 탭에서 적용 중인 연차·결과에는 영향을 주지 않습니다. 비교 미리보기는 화면에서만 유지하며 JSON에는 저장하지 않습니다.

**시나리오 비교 → 비교표 출력**을 누르면 브라우저 인쇄 창이 열립니다. 프린터를 선택하거나 **PDF로 저장**할 수 있습니다. 기본 용지는 **A4 가로, 여백 8mm**이며, 인쇄용 행간·그래프 크기를 줄여 한 장에 배치합니다. 제품명·비고·날짜와 비교 항목·금액·그래프를 포함하며, 입력 화면과 결과 카드는 인쇄하지 않습니다. 인쇄에서는 API 이름을 윗줄, 제조원·단가를 아랫줄에 표시합니다. 최종 인쇄 미리보기에서 용지·배율·페이지 수를 확인할 수 있습니다.

**예제 열기**의 수치는 가상이며 실제 견적·제품·보험약가가 아닙니다. 실제 프로젝트를 작성할 때는 **새 프로젝트**를 사용합니다.

## SF·이익 분석

기존 원가 계산에 판매수량 예측을 더하려면 다음 순서로 사용합니다.

1. 화면 위쪽의 **SF·이익 분석 사용**을 체크합니다. **입력** 탭에 SF 입력표가 나타나고 **시나리오 비교** 옆에 **이익 분석** 탭이 추가됩니다.
2. 분석기간을 **1~10년** 중 선택합니다. 기본값은 8년이며, 연차별 **공통 SF**를 판매수량 **T** 단위로 입력합니다. 0 이상의 정수만 입력할 수 있습니다.
3. 시나리오별 판매 예측이 다르면 **현재 시나리오에 별도 SF 사용**을 체크하고 해당 연도 수량을 입력합니다. 별도 SF의 빈칸은 공통 SF를 사용하며, `0`은 해당 연도의 판매 없음으로 적용합니다.
4. **이익 분석** 탭에서 시나리오별 연간·누적 이익과 차이를 확인하고 프로젝트를 저장합니다.

예상매출은 **SF 수량 × 해당 연차 약가**, 예상 제조원가는 **SF 수량 × 현재 제조원가/T**, 예상이익은 **예상매출 − 예상 제조원가**입니다. 예를 들어 판매수량 100,000T, 약가 300원/T, 제조원가 90원/T이면 매출 30,000,000원, 제조원가 9,000,000원, 예상이익 21,000,000원입니다. 이익 분석의 모든 금액은 **소수점 없는 원** 단위로 표시합니다. 원 단위 반올림은 화면 표시에만 적용하며 내부 계산값은 유지합니다. 직접 입력 약가는 분석기간 동안 유지하고, 예상 약가 계산은 각 연차의 약가를 사용합니다. 제조원가/T는 화면 표시 전 계산값을 전 기간에 유지합니다. 약가를 판매단가로 사용하는 가정이며, **제조원가만 반영한 예상이익**입니다. 판관비·개발비·세금은 포함하지 않습니다.

연차별 묶음 막대그래프는 같은 연도의 시나리오별 예상이익을 나란히 비교합니다. 누적 예상이익도 **연도별로 시나리오 막대를 나란히** 표시하며, 각 막대의 높이는 1년차부터 해당 연차까지의 누적 이익입니다. 음수 누적 이익은 0선 아래에 표시합니다. 미완성 연도부터는 이후 누적 막대를 표시하지 않으며 최종 합계도 확정값으로 표시하지 않습니다. 이후 연도 자체의 이익을 계산할 수 있으면 연차별 예상이익 그래프에는 계속 표시합니다. 누적 비교표의 기준은 **현재 탭 순서의 첫 시나리오**이며, 순서를 바꾸면 차이의 기준도 바뀝니다. 원가율 100% 초과의 손실은 음수로 표시합니다. SF 빈칸·약가 미입력·필수 원가 미완성은 0원 이익으로 대신하지 않으며, 누적 내역과 최종 합계도 미완성임을 표시합니다. 직접 입력 약가가 0원이면 매출은 0원이며 제조원가를 차감한 이익은 계산합니다. 이 경우 원가율만 계산 불가입니다.

SF 사용을 해제하거나 분석기간을 줄여도 공통·별도 SF 입력값은 유지합니다. 최대 10년의 값을 저장하므로 다시 켜거나 기간을 늘리면 복원됩니다. SF 기능은 기존 제조원가와 약가 계산을 바꾸지 않습니다. 자세한 가정과 미입력 처리는 [SF·이익 분석 안내](sf-analysis.md)를 참고하세요.

## 파일 저장과 열기

**프로젝트 저장**을 누르면 브라우저가 JSON 파일을 다운로드합니다. 브라우저 설정에 따라 다운로드 폴더에 저장되거나 위치를 묻습니다. 이 파일이 프로젝트 원본이므로 알아보기 쉬운 이름으로 보관하고, 이후 **파일 열기**로 다시 불러옵니다. 시나리오 전체와 제품 정보·입력값이 하나의 파일에 저장됩니다.

웹 파일은 `format: "pharma-cost-web-project"`, **`schema_version: 5`** 형식입니다. 제품명·비고는 `scenarios[].product`에 저장합니다. 버전 1~4 파일·초안의 공통 제품 정보는 각 시나리오에 독립적으로 복사합니다. 비교표와 출력물도 시나리오별 제품명·비고를 함께 표시합니다. SF 사용 여부·분석기간·공통 판매수량 10개(`profit_analysis.common_quantities`)와 시나리오별 별도 SF 사용 여부·판매수량 10개(`sales_forecast.quantities`)를 함께 저장합니다. 버전 1·2 웹 파일은 기존 입력을 보존하고 SF 기능을 끈 상태로 열립니다. 버전 3의 금액 SF는 `profit_analysis.legacy_amount_forecast`에 기존 단위 `million_krw`로 기록만 보존합니다. 기능 사용 여부·기간과 원료·약가 등 기존 입력은 유지하되, 금액을 수량으로 자동 변환하지 않으므로 판매수량은 새로 입력하세요. 버전 5 파일은 예전 프로그램에서 열 수 없으므로 예전 프로그램을 계속 사용한다면 기존 원본을 따로 보관하세요. 제품·시나리오·원료·비용 외에 약가 모드, 수동 약가 원본, 회사·품목·시장 조건과 **입력 탭의 선택 연차**를 저장합니다. 비교 탭의 연차 미리보기는 저장하지 않습니다. 예상 약가는 저장된 조건으로 다시 계산합니다. 기존 PySide6 데스크톱 JSON은 계산 방식이 달라 자동 변환하지 않습니다. 기존 파일은 그대로 보관하고 기존 데스크톱 프로그램으로 여세요.

포장형태 항목이 없던 이전 웹 파일·브라우저 초안도 열 수 있으며, 해당 항목은 빈칸으로 복원합니다.

웹 버전 1 파일·초안도 이관해서 엽니다. 예전 다중 가산 체크 원본과 수동 약가는 보존하고 새 조건을 추가합니다. 합쳐져 있던 **준혁신형/수급안정 선도기업**, **오리지널/자료제출** 및 여러 가산 선택처럼 의미가 모호한 값은 자동 확정하지 않습니다. 안내에 따라 새 그룹의 선택·요건을 확인하고 **이전 가산조건 확인 완료**를 누르세요. 일반·수급안정 모두 해당 없음인 기존 제네릭 분기는 확인 전 자동 계산이 `추가 산정조건 필요`이며, 직접 입력 금액은 사용할 수 있습니다. 새 간편 가산을 선택하면 이전 상세조건 확인 안내는 계산에 사용하지 않고 보존만 합니다. 예전 목표 원가율과 가산 종료 후 가격은 호환성을 위해 보존하지만 현재 계산에는 사용하지 않습니다.

이전 상세 계산 모델의 개발목표제품 금액·허가 세부유형·인정·기산일·연장·자격 체크는 파일에 보존하되 간편 계산에서 무시합니다. `pricing_conditions.model_id: "simplified-v1"` 표식이 없는 예전 파일에서 `개량신약 + 복합제`로 저장한 선택은 **한 번만 개량신약복합제**로 이관합니다. 새 모델 표식이 붙은 이후에는 사용자가 다시 선택한 분류를 예전 세부값이 덮어쓰지 않습니다. 현재 저장 파일 버전은 4입니다.

시나리오가 4개를 초과하는 파일은 원본 데이터를 자동 삭제하지 않고 오류를 표시하며, 현재 프로젝트를 유지합니다. 브라우저 초안이 4개를 초과해 복원할 수 없는 경우에도 원래 초안 문자열을 보관하고 새 초안으로 덮어쓰지 않습니다. 이 경우 현재 작업은 JSON 파일로 저장하세요.

브라우저 종료나 다른 PC 이동 전에는 JSON 파일로 저장하세요. 다운로드 완료 여부와 저장 위치는 브라우저에서 확인할 수 있습니다. 파일 내용은 암호화되지 않은 일반 JSON입니다.

브라우저가 로컬 저장을 허용하면 입력 중인 초안을 자동 보관하고 같은 브라우저에서 다시 열 때 복원합니다. 로컬 저장을 사용할 수 없는 환경에서는 안내가 표시됩니다. 브라우저 데이터 삭제, 시크릿 모드나 파일 위치 변경 등에 따라 초안이 유지되지 않을 수 있으므로 JSON 저장을 대신하지 않습니다.

저장하지 않은 변경이 있을 때 새 프로젝트·파일 열기·예제 열기로 이동하면 저장 여부를 확인합니다. 브라우저 탭을 닫거나 새로고침할 때도 변경 경고를 요청하지만 실제 표시 방식은 브라우저 정책에 따라 달라집니다.

## GitHub Pages에서 열기

공개 웹 주소가 필요하면 저장소 관리자가 다음과 같이 설정합니다.

1. GitHub 저장소의 **Settings → Pages**로 이동합니다.
2. **Build and deployment → Source**에서 **Deploy from a branch**를 선택합니다.
3. **Branch**를 `main`, 폴더를 **/(root)**로 선택하고 **Save**를 누릅니다.
4. 배포가 끝나면 같은 화면에 표시되는 사이트 링크를 엽니다.

이 저장소는 [https://smoothsea45.github.io/project1/](https://smoothsea45.github.io/project1/)에서 사용할 수 있습니다. 이전 화면이 보이면 `Ctrl+F5`로 새로고침하세요. 다른 저장소에 배포할 때는 설정·권한·GitHub 요금제에 따라 Pages 사용 여부가 달라질 수 있습니다. 최초 구성에는 GitHub Actions 파일이 필요하지 않습니다.

Pages에서는 프로그램 파일을 웹에서 내려받지만, 입력값 계산과 프로젝트 파일 처리는 브라우저 안에서 이루어집니다. 인터넷이 없는 PC에서는 앞의 ZIP 다운로드 방식을 사용하세요.

## 개발 검증

프로그램 사용에는 Node.js가 필요하지 않습니다. 개발자는 Node.js가 있는 환경의 저장소 루트에서 계산·파일 검증 테스트를 실행할 수 있습니다.

```bash
node --test web/tests/*.cjs
```

브라우저 테스트에는 Playwright와 Chromium이 필요합니다. 개발용 의존성을 설치한 다음 실행합니다.

```bash
python -m pip install -r web/requirements-test.txt
python -m playwright install chromium
python -m pytest web/tests
```

이미 Chromium이 설치되어 있다면 다운로드 대신 `CHROMIUM_EXECUTABLE`에 실행파일 경로를 지정할 수 있습니다. 이 클라우드에서는 `/usr/bin/chromium`을 사용했습니다.

Node 테스트는 SF·이익 계산과 파일 호환성, 제조원가·일반 제네릭·간편 일정·우선순위·종료 후 가격·날짜·반올림·JSON 이관과 보존을 검증합니다. 브라우저 테스트는 SF 사용 전환·기간·별도 SF·이익 그래프·비교표와 저장, 실제 비활성화·수동값 보존·10개 세로 막대·별도 비교 미리보기·누적 막대와 연차별 원가율·시나리오 공통 축·단가의 두 통화 환산·표시 정밀도·도넛 연차 배지·저장과 열기·오프라인 실행을 확인합니다. PDF 테스트는 비교표 출력을 검증합니다. 최종 통과 수와 실행 환경은 완료 보고 또는 위 명령의 출력으로 확인하세요. 서버는 브라우저 테스트를 위해 잠깐 실행하고 종료하며, 실제 프로그램의 계산·파일 처리는 서버 없이 수행합니다.
