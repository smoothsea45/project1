# 예상 약가의 간편 모델과 공식 규정 조사 기록

갱신일: 2026-10-15. 현재 약제별 일반·수급안정 가산은 **사용자가 승인한 간편 시뮬레이션 모델**이다. 공식 고시의 세부 산정·자격·가산 규칙을 그대로 구현한 결과가 아니다. 공식 원문 조사는 아래에 역사 기록과 향후 확장 자료로 보존한다. 실행 중 외부 사이트에 접속하지 않는다.

## 현재 구현: 사용자 지정 간편 모델

일반 또는 수급안정 가산을 선택하면 결과 메타데이터는 `model: "simplified-v1"`, `regulation: null`, `basis_date: null`, `links: []`로 반환한다. 법정 산정 출처를 붙이지 않고 화면에도 간편 가정으로 표시한다. JSON 조건에는 `model_id: "simplified-v1"`를 저장한다.

**모든 간편 비율은 입력한 오리지널 기준약가에 직접 곱한다.** 기간 합산과 연장 가정은 자동 적용한다.

| 선택 | 적용 일정 | 가산 종료 후 |
|---|---|---|
| 자료제출의약품 | 1년차 70%, 2~4년차 60% | 기본 산정요건별 45/36/29% |
| 개량신약 | 1~4년차 70% (1년 + 3년) | 5년차부터 기본 산정요건별 45/36/29% |
| 개량신약복합제 | 1~4년차 68% (1년 + 3년) | 5년차부터 기본 산정요건별 45/36/29% |
| 기타 | 1~4년차 60% | 기본 산정요건별 45/36/29% |
| 생물의약품 | 1~5년차 80% | 70% |
| 수급안정 3종 | 1~5년차 68%, 6~10년차 68% | 10년 표시 범위에서는 종료 없음 |

수급안정 3종은 원료직접생산, 국산 원료 사용 국가필수, 직접 생산 항생주사제/소아용의약품이다. 뒤 5년은 **연장요건 충족 가정**으로 구분한다. 실제 최초요건·회사 수·직접생산·임상·허가형태를 검증했다는 의미가 아니다.

현재 간편 모델의 적용 순서와 제외사항:

1. 일반과 수급안정이 함께 선택되면 **수급안정 일정 하나를 우선**한다. 기업·일반·수급안정 가산 금액이나 기간을 합산하지 않는다.
2. 간편 일정에는 기업가산·동일제제 14개 이상 감액을 추가 적용하지 않는다.
3. 비생물 일반가산이 끝나면 기본요건 체크 두 개/한 개/없음에 따라 오리지널 기준약가의 45/36/29%를 사용한다. 생물은 70%다. 이는 사용자가 승인한 회복가격 가정이다.
4. 과거 상세 입력은 JSON에 보존하지만 간편 계산에 사용하지 않는다. 개발목표제품 금액·세부유형·자사제품 여부·인정·기산일·자격·연장 체크가 비어 있어도 간편 일정은 계산한다.
5. 결과 금액은 원 단위 반올림한다. 제조원가의 중간 정밀도와 비용 계산식은 변경하지 않는다.

따라서 예전의 '복합제·생물·가산 겹침·실제 기산일 확인 전 추가 산정조건 필요' 처리는 **간편 모델에는 적용하지 않는다.** 가격·예상 등재일 등 현재 필요한 입력이 유효하지 않으면 안내하고 약가를 확정하지 않는다. 간편 가산을 선택한 경우에는 예전 세부조건 검토 안내를 계산에 사용하지 않고 원본 문자열만 보존한다. 구버전 선택 재확인 절차는 일반·수급안정 모두 해당 없음인 기존 제네릭 분기에만 적용한다.

## 현재 유지하는 일반 제네릭 분기

일반·수급안정이 모두 `해당 없음`이면 기존 일반 제네릭 규칙을 유지한다. 이 결과는 `model: "generic-regulation-v1"`이며 사용자가 지정한 2026-08-01 별표 기준정보를 반환한다. 기준요건 45/36/29%, 대상 단일제의 기업가산, 국내생산 연장, 정확히 14개 이상 감액, 단계별 원 단위 반올림은 아래 조사 내용에 근거한다. 최초 제네릭 등재군과 입력 등재일 기산 가정은 그대로다. API 복수 행은 단일제 여부를 확정하지 않고 기업가산을 제외한다.

전체 자동 계산이 공식 고시에 부합한다고 표시하지 않는다. **간편 가정 분기와 기존 일반 제네릭 규정 분기를 구분**한다. 실거래가·사용량 연동·기등재 재평가 등 사후 조정은 어느 모델도 예측하지 않는다.

## 저장과 비교 미리보기

파일 형식은 웹 JSON 버전 2를 유지한다. `model_id`가 없는 예전 상세 조건 중 `general_category: "improved"`와 `general_subtype: "combination"` 조합은 개량신약복합제로 한 번 이관하고 표식을 붙인다. 상세 원본은 보존하며 표식이 있으면 옛 세부유형으로 다시 분류하지 않는다.

입력 탭의 선택 연차는 프로젝트에 저장한다. 비교 탭은 시나리오마다 별도 1년차 미리보기를 시작하고, 막대 선택 시 해당 열의 약가·원가율·도넛과 왼쪽 위의 연차 배지를 갱신한다. 이 선택은 입력 탭·다른 시나리오에 영향을 주지 않으며 파일에 저장하지 않는다. 직접 입력은 10년 동일 가격 유지 가정이다. 비교 그래프는 약가 뒤쪽에 실제 제조원가의 좁은 막대를 겹쳐 표시한다. 비교하는 모든 시나리오의 10년 약가와 제조원가 중 최대값을 포함하는 하나의 공통 축을 사용한다.

## 일반 제네릭: 원문에서 확인한 규칙

### 기본약가와 기준요건

제2호가목(1)(가)~(다), PDF 4~5쪽:

> 신청제품이 다음의 표1의 요건을 모두 충족할 경우에는 기 등재된 동일제제 상한금액의 45% …
>
> … 요건 중 1가지만을 충족할 경우에는 … 36% …
>
> … 요건을 모두 충족하지 못할 경우에는 … 29% …

동일제제가 1개인 경우의 산정 규정이다. 마약은 별도 비율이며, 생물의약품은 (마)의 70% 규정이므로 일반 제네릭의 45%를 일괄 사용하지 않는다.

표1의 두 요건은 자체 생물학적동등성시험·임상시험 입증 자료 제출과 등록된 원료의약품 사용 입증 서류 제출이다. 복합제의 등록 원료 기준은 모든 주 약리성분에 해당한다. 표1의 단서, PDF 6쪽:

> … 기준 요건 중 하나 혹은 전부가 제외되는 의약품인 경우 제외되는 요건은 기준 요건을 충족한 것으로 본다.
>
> 위임형 후발의약품 또는 국산 원료의약품을 사용한 국가필수의약품의 경우도 기준요건을 모두 충족한 것으로 본다.

따라서 요건 체크는 실제 시험 수행 여부만이 아니라 법정 제외·면제에 따른 충족 간주를 포함한다. 국산 원료 사용 국가필수의약품의 자격이 확인되면 개별 체크가 꺼져 있어도 두 요건 충족으로 처리하고 사유를 남길 수 있다. **원료 직접 생산 선택만으로 두 요건 충족을 간주하지 않는다.**

### 기업별 가산

제4호가목(1), PDF 12~13쪽은 표1의 기준요건을 모두 충족할 것을 전제로 한다. 제4호가목(1)(가)는 마약·생물의약품·복합제를 제외한다.

> 혁신형 제약기업의 제품인 경우 : (60/45 － 1)×100%
>
> 준혁신형제약기업 또는 수급안정 선도기업의 제품인 경우 : (50/45 － 1)×100%

가산 후 금액은 **이미 산정된 기본약가 × 60/45 또는 50/45**다. 기준요건 미충족 품목에 기업 자격만으로 가산하지 않는다. 최초등재제품 중 최고가 제품의 조정 전 상한금액 제한도 확인한다.

제4호나목(1), (3)(가), PDF 15~16쪽: 기본 1년, 국내 생산 연장요건 충족 시 기산일부터 최대 4년이다. 국내 생산은 포장 이전 모든 생산 공정이 국내 제조소에서 수행되는 것을 뜻한다. 기업 자격 선택만으로 4년을 적용하지 않는다.

### 수급안정 가산과 직접 생산 세부요건

제4호가목(7), PDF 14쪽:

> 국산 원료의약품을 사용한 국가필수의약품 또는 원료직접생산의약품 … 산정된 금액에 (68/45 - 1)×100%를 가산하되 … 기준요건을 모두 충족하는 제품인 경우에만 가산한다.

마약과 생물의약품은 제외된다. 제4호가목(8), PDF 15쪽은 항생주사제·소아용의약품에 다음을 **모두** 요구한다.

- WHO ATC J의 주사제 항생주사제, 또는 WHO 소아용 필수의약품 목록의 내복제로서 GN·PD·LQ·SY·SS·EL 제형.
- 품목허가권자의 자사에서 포장단계 이전의 모든 생산 공정을 직접 수행.
- 투여경로·성분·제형이 동일한 제품의 회사 수가 신청 회사를 포함해 3개 이하.

회사 수는 동일제제 품목 수 14개 경계와 다른 조건이다. 정제·캡슐의 원가 입력만으로 항생주사제·소아용의약품 자격을 추론하지 않는다. 별도 세부요건 확인이 필요하다.

제4호나목(6), PDF 17쪽:

> … 최초 고시 시행일로부터 5년간 가산 … 가산요건을 충족할 경우 추가 5년간 가산기간을 연장할 수 있다.

6~10년차 유지는 사용자의 **연장요건 충족 가정**이다. 제4호다목(4)은 기존 가산 중 수급안정 가산요건을 충족하면 가산금액을 재산정하는 경로를 둔다. 기업가산을 더하거나 기간을 순차로 연결하는 규칙이 아니다.

### 정확히 14개 포함, 가산 종료 후 감액

제2호가목(4), PDF 6쪽:

> … 신청제품과 이미 등재된 동일제제와의 합이 14개 이상이 되는 경우 … 산정되는 금액의 85%로 산정한다.
>
> … 제4호가목에 따라 가산되는 신청제품의 경우에는 가산 종료일의 다음 날부터 … 산정되는 금액의 85%로 산정한다.

대상 경로는 제2호가목(1)(가)·(나)·(다)·(바), (2)(가)·(나)·(다)다. **정확히 14개도 포함**하며, 가산을 받으면 가산 종료 후 기본 산정금액에 85%를 적용한다. 다른 경로의 자료제출의약품·생물의약품에 자동 적용하지 않는다.

### 금액 반올림

제5호아목, PDF 19쪽:

> 상한금액 산정, 조정 및 가산 시 각 단계에서 산출된 금액은 반올림하여 원단위까지 반영하고, 제2호나목(2) 표2의 B, B' 값은 반올림하여 소수 둘째자리까지 반영한다.

기본약가·가산약가·감액약가를 단계별로 원 단위 반올림한다. 예: 450원의 85%는 382.5원 → 383원. 이는 예상 약가 산정에만 적용하며, 기존 제조원가 중간 계산은 반올림하지 않는다.

## 약제별 일반가산: 별도 산정 경로

### 비생물 자료제출의약품·개량신약 단일제

제2호나목(1) → 별첨1, PDF 21~23쪽. 기준금액은 **개발목표제품의 상한금액**이다. 일반 제네릭의 최초 진입 전 오리지널 기준약가를 대신 넣지 않는다.

|---|---:|---:|
| 염변경·이성체, 새로운 제형 | 개발목표제품 상한금액의 90% | 100% |
| 새로운 용법·용량 | 개발목표제품 상한금액의 100% | 110% |

왼쪽 90% 경로에서 목표제품이 자사제품인 경우 100% 단서가 있으나, 주3에 따라 주사제 또는 새로운 제형에 한정된다. 오른쪽에서 개발목표제품이 생물의약품이면 64.3%·70.7%이므로 구분한다. 주2에 따라 임상적 유용성 개선이 없는 새로운 용법·용량은 염변경·새 제형 경로로 취급한다. 주4는 **투약비용 기준 산정**을 요구한다. 단위당 입력액을 사용하려면 신청제품과 비교제품의 투약비용 기준이 같은지 확인해야 한다.

제4호가목(2), PDF 13쪽:

> 제2호나목(1) 별첨1에 따라 산정된 최초등재제품의 경우(다만 … 개발목표제품과 동일제제가 등재되어 있는 경우에만 해당한다) 산정된 금액에 (70/45 － 1)×100%를 가산한다.

이는 별첨1로 **산정된 금액**에 곱한다. 오리지널 약가의 70%가 아니다. 이 항에는 제4호가목(1)과 같은 별도 상한 단서가 없다.

기간과 추가 확인:

- 제4호나목(1)(가): 해당 제품의 최초 고시 시행일과 개발목표제품 조정 원인 제품의 최초 고시 시행일 중 선행일로 기산한다. 예상 등재일 하나로 무조건 기산하지 않는다.
- 제4호나목(3)(나): 국내 생산 또는 동일 투여경로·성분·제형 회사 수 3개 이하 조건에 따라 최대 4년 연장이 가능하다.
- **개량신약이 아닌 자료제출의약품**은 연장 시 제4호가목(9), 다목(3)에 따라 70/45 대신 60/45로 재산정한다. 조정 전 상한금액 제한도 있다. 개량신약 인정 여부를 구분해 저장해야 한다.
- 제4호나목(4): 개량신약이며 해당 회사 수가 1개이면 2개 이상이 될 때까지 4년 이후 가산이 유지되는 별도 경로가 있다. 확정된 10년 혜택으로 취급하지 않는다.
- 기준금액·세부유형·최초등재 자격·투약비용 대응·기산일·연장상한 등 필요한 사실이 부족하면 `추가 산정조건 필요`를 반환한다. 일반 제네릭 45%로 대체하지 않는다.

### 개량신약복합제

제2호나목(3), PDF 9~10쪽: 기등재 개별 단일제·복합제의 성분별 가격 합산, 함량 조정, 일부 성분 가감, 1일 투약비용 등 산정 경로가 다르다. 별첨1로 산정할 수 있는 경로도 있다. 따라서 단일 오리지널 금액만으로 기본약가를 결정할 수 없다.

제4호가목(1)(나), PDF 12~13쪽: 해당 개량신약복합제는 산정된 금액에 60/45, 혁신형 제약기업 제품은 68/45다. **별첨1 또는 제2호나목(3)(바) 산정은 제외**된다. 표1 요건과 최초등재제품 조정 전 최고 상한금액 제한도 필요하다. 제4호나목(3)(나)·(4)(나) 연장에는 회사 수와 구성 개별제품의 회사 수가 영향을 준다.

단순한 '개량신약 인정'과 금액 하나만으로 전체 경로가 검증되었다고 볼 수 없다. 구성품별 비교금액·적용 경로가 없으면 `추가 산정조건 필요`로 안내한다.

### 생물의약품

생물의약품에는 동등생물의약품, 별첨2 자료제출의약품, 개량생물의약품이 있어 세부유형이 필요하다.

- 제2호가목(1)(마), PDF 5쪽: 동일제제 1개 경로의 기본약가 70%. 제2호가목(2)(라)의 2~12개 경로는 최저가 동일가다.
- 제4호가목(5), PDF 13~14쪽: 대상 동등생물의약품이 국내 허가 임상 1·2·3상 중 하나를 수행하고, 혁신형 또는 평가위 인정 기업·인정된 국내외 공동개발·한국 최초허가·인정된 국내 전공정 생산 중 하나를 충족하면 산정금액에 **80/70**을 적용한다. 최초등재제품 중 최고가의 조정 전 상한금액 제한이 있다. 제3호가목·다목·별첨2로 조정된 생물의약품의 동등생물의약품은 제외된다.
- 제4호나목(1), (2), PDF 15~16쪽: 기본 1년, 동일 투여경로·성분·제형 회사 수 3개 이하이면 최대 5년 유지. 일반 제네릭의 국내 생산 4년 규칙과 다르다.
- 별첨2, PDF 24~26쪽: 자료제출 생물의약품은 목표 동일제제 유무에 따라 100% 또는 110%, 개량생물의약품은 110% 또는 120%다. 이후 조정도 77%·76.3% 등 별도 규정이다.
- 생물의약품 선택만으로 70%·80%를 확정하거나 일반 제네릭의 14개 감액·68/45 수급안정 가산을 적용하지 않는다.

## 이전 상세 모델에서 사용한 시뮬레이션 가정

다음은 간편 모델로 바꾸기 전 상세 모델의 범위 기록이다. 현재 약제별 가산은 문서 상단의 간편 일정으로 대체했으며, 아래 추가 조건 차단을 그대로 사용하지 않는다.

1. 일반 제네릭은 특허 만료 후 **최초 제네릭 등재군**에 참여한다. 현재 오리지널 약가와 최초 진입 전 기준가격을 혼동하지 않는다.
2. 이 경로는 입력 예상 등재일과 가산 기산일이 같다고 가정한다. 후속 진입·기등재 최저가·이전 계단식 산정 이력은 제외한다.
3. 품목 수에는 오리지널과 우리 제품을 포함하며, 최초 진입 시 14개 미만/이상 판단을 고정한다. 별도 회사 수 조건을 이 선택으로 대신하지 않는다.
4. 수급안정 6~10년차는 연장요건 충족 가정이다. 공급회사 수 변화·자격 상실 등의 발생시점은 별도로 예측하지 않는다.
5. 자료제출·개량신약 등의 향후 다른 제품 등재에 따른 새 조정, 기등재 재평가·실거래가·사용량-약가 연동은 예측에서 제외한다. 확인되지 않은 경로에는 약가를 만들지 않는다.
6. 등재일부터 달력 기준 1년씩 10개 연차를 보여주었다. 당시 상세 일반가산은 실제 가산 기산일과 예상 등재일이 같은 경로만 지원하고, 기산일이 다른 경우 `추가 산정조건 필요`를 반환했다. 현재 간편 모델은 입력 등재일부터 승인된 일정을 적용하며 이전 기산일 필드를 무시한다.

직접 입력 모드는 위 조건과 독립적이다. 수동 약가 원본은 보존하고 자동 결과로 덮어쓰지 않는다. 원가율의 분모는 현재 모드의 실제 적용 약가 하나다. 자동 조건 부족은 원가율 `계산 불가`로 연결하며 이전 금액을 남기지 않는다.
